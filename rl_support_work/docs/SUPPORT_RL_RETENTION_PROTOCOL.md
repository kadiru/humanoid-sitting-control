# Fixed-progression retention experiment

Written before training or evaluating either candidate. The last pace experiment regressed; this study starts from the preserved pilot-3 parent, never its regressed successor. It removes the added pace action entirely. It does not claim to solve every stochastic/deterministic control difference or establish pace as the sole cause of the prior failure.

Parent: `/data/humanoid-sitting-perception/support_rl_independent_train_04/final.pt`, SHA256 `2c0f6907196be68bce9a1ee2e6b6ef6e4c82bf0ecdff622dc55b81fe8ef58d13`.

Two matched arms use the original 144 sensor channels and 23 bounded joint residuals, original fixed progression of one, unchanged reward and limits, 16 robots, 32 PPO updates of 64 steps (32,768 transitions each), seed 51713 and learning rate 3e-5. Both start with exact parent actor/critic weights and Gaussian joint standard deviations, fresh optimizers, and frozen parent actor/critic observation-normalization statistics. Frozen statistics avoid function drift outside the loss; their effect is not isolated by this study. The control is therefore matched fixed-normalizer PPO, not an exact repeat of historical pilot 3.

The sole arm difference is coefficient zero versus one on KL(parent || current), summed over the 23 Gaussian action coordinates and averaged over the minibatch. Parent parameters, normalizer and outputs are detached. This is a soft penalty on current training observations, not a mathematical guarantee of trajectory retention. No evaluation observations are used for training. The parent is training-only; the candidate remains a single actor at runtime.

Both use the exact previously placement-validated TRAINING bank from `support_rl_pace_mixed_train_02/geometry_bank.json`: eight easier prototypes plus the first eight of the older wider training bank, selected in original order before any evaluation. No new geometry generator or evaluation shapes enter training. Bank bytes and hashes are archived. Geometry seed argument is 51621; loading the archived bank takes precedence. Starts are independently randomized at resets with seed 51713.

Checks before training: coefficient-zero update matches installed RSL-RL PPO exactly on identical synthetic sensor batches and RNG; positive coefficient has the expected mean gradient and changes a real PPO update; parent and normalizer weights stay frozen; optimizer excludes the parent. Both arms use the same code. Package source is archived and never edited. The full-horizon parent regression run must reproduce the existing easier reference traces exactly before candidate evaluation is accepted.

Retention gate: evaluate each final checkpoint on the already-known easier bank (geometry seed 51403, start seed 51407), eight shapes x two starts, full 20 seconds. Require 16/16 successes with the existing latched failures, initial standing and at least three seconds continuous support. Existing impact criterion remains two robot body weights. No early stopping or best-checkpoint selection. If an arm fails retention, stop that arm; do not expand training or evaluate a fresh holdout.

Only an arm that passes retention receives the known wider bank (51541/51543). A further fresh holdout is warranted only if it preserves every parent success on this known bank, gains at least one success, and does not increase its worst full-trial impact relative to the parent. If both pass, evaluate both; no choosing the winner from holdout. Reserve fresh seeds 51741/51743 (eight shapes, two starts) for that conditional paired test. Freeze checkpoint and settings before using that bank.

All completed and unfinished transitions must account for the exact budget. Audit sensor-only observations, source/checkpoint hashes, normalizer equality, nonzero finite actor changes, measured joint sampling/clipping, full trial duration, and accepted depth clearance errors. Preserve failed/debug runs and existing checkpoints. Large outputs go to `/data`; no reinstall or hardware deployment. No deployment default changes automatically.
