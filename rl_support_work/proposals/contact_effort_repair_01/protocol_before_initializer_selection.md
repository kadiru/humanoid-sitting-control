# Repaired sitting: bounded effort PPO pilot

This study implements the user's authorized contact repair and small comparison. It is independent of the completed leaning pilot. Prior studies, criteria, sources and checkpoints are preserved. Work runs directly on Ubuntu from this Mac; no other coding agent.

Admission requires the measured-plane/foot-anchored reference, both original starting policies with that repaired reference, and zero-child replays to pass all18 development trials for20 seconds. Indexed reset isolation, exact physical/sensor starts, exact zero-child trajectories, sensor-only path reconstruction, loaded checkpoint identity, finite metrics and unchanged1192 prior hashes must pass. Development has nine38/40/42cm,−5/0/+5degree geometries, each repeated twice. The selected reference is `transfer15_pitch55`, fixed before training. Controller gains must be reported separately from learned gains.

The repair preserves the initial standing state and seven-stage reference convention. Depth and encoder/IMU calibration determine relative plane height/slope; foot-preserving inverse kinematics changes the final approach/contact poses. A forward torso lean establishes rearward weight transfer above the seat before lowering. The pelvis target reaches x=−.15m in the explicit offline reference coordinate system; feet remain anchored to their initial encoder/IMU frame. The ankle controller adds bounded feedback from this kinematic pelvis-position estimate. The original37-joint robot, rigid surfaces, allowed support patches,10N forbidden-contact limit,2-bodyweight impact limit, joint/torque limits, friction margin, and full20s/final5s success criteria remain unchanged. This is reference-assisted control on static slabs, not arbitrary surface discovery or moving-seat tracking.

No simulator truth enters actor/critic/controller inputs; it is used for reward, reset and offline evaluation labels only.
